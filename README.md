# 자인사진관: AI 기반 나의 퍼스널 컬러 찾기

특수학교 학생이 학습지(활동1) 순서에 따라 **나에게 어울리는 색을 직접 찾고**, 그 색을 적용한 3:4 증명사진을 만드는 Next.js/Vercel 프로젝트입니다.

> 표현 원칙: "장애가 없었다면"의 외모를 추정하지 않고, 촬영 순간의 제약을 보완해 본인의 단정하고 자신감 있는 모습을 구현합니다.

## 화면 순서 (학습지 연계)

| 순서 | 화면 | 학습지 |
|---|---|---|
| 1 | 이름 쓰기 | 1번 |
| 2 | 사진 촬영 또는 업로드(2~3장) | |
| 3 | 남학생, 여학생 선택 | |
| 4 | 좋아하는 색 카드(10색) | 2번 |
| 5 | AI 진단 추천 + 옷 색 비교(내 사진 + 색 카드) 중 선택 | 3번 |
| 6 | 계절별 추천 색 중 나의 색 최종 선택 | |
| 7 | 옷 종류 단계 선택 | 4번 |
| 8 | 표정(활짝 웃는 얼굴, 웃는 얼굴, 차분한 얼굴) | 6번 |
| 9 | 배경색(파스텔 피치, 분홍, 라벤더, 베이지 + 흰색, 하늘색, 회색) | 7번 |
| 10 | 증명사진 생성, 저장, 10×15cm 인쇄 | |

- 모든 단계에 브라우저 음성 안내(다시 듣기, 소리 켜기/끄기)
- 옷 종류: 남학생 정장(정장 색 → 셔츠는 나의 색, 넥타이 자동) 또는 캐주얼(남방, 니트) / 여학생 정장, 블라우스, 가디건
- 나의 색은 셔츠, 블라우스, 니트, 가디건에 적용

## 퍼스널 컬러 진단 방식

| 구분 | 내용 |
|---|---|
| 사진 분석 | 피부, 눈동자, 머리색, 대비를 보고 4계절 점수(합 100) 산출, 옷, 배경, 조명 색은 제외 |
| 학습지 반영 | 좋아하는 색이 속한 계절에 +15점 |
| 결과 표시 | 비교 사진 화면에 'AI 추천' 표시, 최종 선택은 학생 |
| 교사 확인 | 사진 분석 결과, 점수, 신뢰도, 관찰 메모(접기 메뉴) |

## 증명사진 보정 방식 (1회 통합 생성)

| 항목 | 내용 |
|---|---|
| 생성 구조 | 1회 통합 생성(헤어, 얼굴, 의상, 배경을 한 번에), 실패 시 이미지 편집 API로 자동 대체 |
| 헤어 | 머리색, 헤어라인, 길이는 유지, 잔머리 제거, 윤곽선과 볼륨 정돈, 은은한 윤기 |
| 얼굴 | 원본보다 한 단계 밝게, 칙칙함과 수염 자국, 유분광 완화, 건강한 혈색 |
| 조명, 배경 | 하이키 사진관 조명, 파스텔 그라데이션 배경 |
| 동일 인물 | 눈, 코, 입 모양과 얼굴형 유지(input_fidelity) |

- 결과 화면에 생성 방식(1회 통합 생성 / 1회 생성 대체 방식) 표시
- 머리 정돈이나 밝기가 약하게 나오면 Vercel 환경변수 `OPENAI_INPUT_FIDELITY`를 `low`로 바꿔 비교(얼굴 유지는 약간 느슨해짐)

## 파일 구성

| 파일 | 역할 |
|---|---|
| app/page.js | 단계형 화면, 음성 안내 |
| app/Intro.js | 인트로 화면 (public/intro.png) |
| app/lib/colors.js | 좋아하는 색, 계절별 추천 색 |
| app/lib/prompts.js | 최종 증명사진 프롬프트, 비교 사진 프롬프트 |
| app/api/compare/route.js | AI 비교 사진 생성 (현재 화면에서는 사용하지 않음, 보관용) |
| app/api/generate/route.js | 최종 증명사진 1회 통합 생성 (헤어 정돈, 밝은 얼굴) |
| app/api/diagnose/route.js | 퍼스널 컬러 진단 (사진 분석 + 좋아하는 색) |

## 환경변수 (Vercel)

- `OPENAI_API_KEY` (필수)
- `OPENAI_IMAGE_MODEL` (선택, 기본값 `gpt-image-2.5-sunburst`)
- `OPENAI_RESPONSE_MODEL` (선택, 증명사진 생성용, 기본값 `gpt-6-astra`)
- `OPENAI_INPUT_FIDELITY` (선택, `high` 기본 / `low`는 헤어, 피부 보정이 더 강하게 들어감)
- `OPENAI_VISION_MODEL` (선택, 진단용, 지정하지 않으면 `OPENAI_RESPONSE_MODEL` 사용)

실제 키는 Vercel 환경변수에만 입력하고 `.env` 파일은 GitHub에 올리지 않습니다.

## 개인정보, 학교 현장 주의

- 학생 얼굴 사진은 생성 과정에서 해외 AI 업체(OpenAI) 서버로 전송됩니다. 보호자 동의서에 이를 명시하세요.
- 이름은 화면과 인쇄물에만 쓰이고 서버로 전송하지 않습니다. 사진을 별도로 저장하는 기능은 없습니다.
- AI 결과는 법정 신분증 규격과 다를 수 있으므로 공식 제출용은 해당 기관 규정을 확인하세요.
