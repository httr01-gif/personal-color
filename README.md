# AI 증명사진 스튜디오

특수학교 등에서 촬영이 쉽지 않은 학생의 여러 사진(최대 8장)을 참고해, 시선·표정·헤어·자세를 정돈한 3:4 증명사진을 생성하는 Next.js/Vercel 프로젝트입니다.

> 표현 원칙: 이 앱은 "장애가 없었다면"의 외모를 추정하는 것이 아니라, 촬영 순간의 제약을 보완해 본인의 단정하고 자신감 있는 모습을 구현하는 것을 목표로 합니다.

## 핵심 기능

- 사진 업로드 1~8장
- 브라우저 카메라 1컷 촬영 또는 연속 최대 8컷 촬영
- 여러 참고 사진을 OpenAI 이미지 편집 API에 함께 전달
- 강한 사진관/배우 프로필 수준 보정 고정 적용
- 남학생/여학생/공용 스타일
- 의상 프리셋: 블랙/네이비/그레이 정장, 화이트/블루/네이비/블랙 셔츠, 남방, 니트, 블라우스, 가디건 등
- 배경: 연회색/화이트/연하늘
- 단독 JPG 저장
- 10×15cm 포토용지에 3×4cm 증명사진 1/4/6/8/9매 출력
- API 키는 서버에만 저장

## OpenAI API

기본 모델은 `.env`의 `OPENAI_IMAGE_MODEL`로 지정합니다.

```env
OPENAI_API_KEY=sk-...
OPENAI_IMAGE_MODEL=gpt-image-2.5-sunburst
```

현재 코드에서는 `images.edit`에 동일 인물의 사진을 최대 8장 전달하고, 3:4 결과를 `1152x1536`, JPEG, 고품질로 요청합니다.

OpenAI Node SDK의 GPT Image 편집 API는 여러 입력 이미지를 지원합니다. 최신 SDK 사용을 권장합니다.

## Vercel 업로드

### 1) GitHub 없이 직접 배포

1. 이 폴더 전체를 ZIP 해제합니다.
2. Vercel에서 **Add New → Project**.
3. 폴더를 Git 저장소에 올려 Import하거나 Vercel CLI로 배포합니다.
4. Project → Settings → Environment Variables에서 아래 값을 등록합니다.
   - `OPENAI_API_KEY`
   - `OPENAI_IMAGE_MODEL` = `gpt-image-2.5-sunburst`
5. 재배포합니다.

### 2) Vercel CLI

```bash
npm install
npm run dev
# 로컬 확인 후
npx vercel
```

## 인쇄 설정

포토 프린트 용지 규격: **가로 10cm × 세로 15cm**

- 브라우저 인쇄에서 용지 크기를 10×15cm(4×6인치 계열)에 맞춥니다.
- 배율 100%, 여백 없음(또는 프린터가 허용하는 최소 여백) 권장.
- 3×4cm 사진 9매는 3열×3행 = 9×12cm 영역에 들어가며, 남는 공간은 중앙 여백으로 사용됩니다.
- 프린터 자체의 "페이지에 맞춤" 기능은 끄는 것이 실물 크기 유지에 유리합니다.

## 개인정보/학교 현장 주의

- 학생 얼굴 사진은 개인정보이므로 학교 내부 기준과 보호자 동의 절차를 확인하세요.
- 원본 이미지를 별도 DB에 저장하는 기능은 넣지 않았습니다. 브라우저에서 선택한 이미지는 생성 요청 시 서버를 거쳐 API로 전송됩니다.
- 운영 환경에서는 접근 인증(교직원 로그인), 사용 로그 최소화, 보관 정책, 자동 삭제 정책을 추가하는 것을 권장합니다.
- AI 생성 결과는 공식 신분증 발급 규격과 다를 수 있으므로, 주민등록증/여권 등 법정 신분증 제출용은 해당 기관의 사진 규정을 별도로 확인하세요.
